# ⚡ Calculadora de Consumo de Energia

## 📌 Sobre o projeto

A **Calculadora de Consumo de Energia** é um programa desenvolvido em Python que permite calcular uma estimativa do consumo mensal de energia elétrica de um aparelho.
Para realizar o cálculo, o usuário informa o nome do aparelho, sua potência em watts e a quantidade de horas de uso por dia.

## 🎯 Objetivo

O objetivo do projeto é praticar conceitos básicos de programação em Python, como:

* Entrada de dados;
* Conversão de tipos;
* Operações matemáticas;
* Processamento de informações;
* Exibição de resultados.

## 🐍 Linguagem utilizada

O projeto foi desenvolvido utilizando **Python**.

## 🧮 Fórmula utilizada

O consumo mensal é calculado através da seguinte fórmula:

```text
Consumo mensal = (Potência × Horas por dia × 30) ÷ 1000
```
