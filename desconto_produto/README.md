# 🛒 Calculadora de Desconto em Python

## 📌 Sobre o projeto

Este projeto é um programa desenvolvido em **Python** que calcula o valor final de um produto após aplicar um desconto de acordo com o seu preço.

O programa solicita o preço do produto, identifica automaticamente a porcentagem de desconto correspondente e apresenta o **valor final com desconto**.

## 🎯 Objetivo

Praticar conceitos básicos de programação em Python, como:

* Entrada de dados com `input()`
* Conversão de valores com `float()`
* Estruturas condicionais `if`, `elif` e `else`
* Operações matemáticas
* Exibição de resultados com `print()`
* Formatação de valores monetários

## 💰 Regras de desconto

O desconto é definido de acordo com o preço do produto:

| Preço do produto           | Desconto |
| -------------------------- | -------: |
| Menor que R$ 200,00        |       5% |
| De R$ 200,00 até R$ 299,99 |      10% |
| R$ 300,00 ou mais          |      15% |

### 🧮 Fórmula utilizada

O valor final é calculado através da seguinte fórmula:

```text
valor_final = preco - (preco * desconto / 100)
```

### 💻 Exemplo

Se o produto custa **R$ 250,00**:

```text
Preço: R$ 250,00
Desconto: 10%
Valor final: R$ 225,00
```
